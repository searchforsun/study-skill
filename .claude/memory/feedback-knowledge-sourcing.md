name: 知识来源四准则
description: tech-domain-learning 技能的所有知识产出必须来自稳定、可信、真实、前沿的来源
type: feedback
---

tech-domain-learning 技能生成的所有内容（ROADMAP、THEORY、demo）中的知识必须满足四准则：

- **稳定**：优先引用官方文档、正式出版物、长期维护的权威项目；避免个人博客、临时页面
- **可信**：信息来源可追溯——官方 docs 域名、知名出版机构、Apache/CNCF 等基金会项目页面
- **真实**：所有 URL 经 WebSearch 验证可访问；API 名称、版本号、配置项与官方文档一致
- **前沿**：核对当前主流稳定版本与社区推荐实践，避免传播已废弃方案

**Why:** 用户明确要求学习内容的知识来源必须可靠，不能是编造的 URL、过时的方案或低质量的第三方内容。

**How to apply:** 每次执行工作流 A（初始化）或工作流 B（生成阶段）时，必须用 WebSearch 验证所有外部引用；URL 只使用官方文档或权威出版物链接；不编造 API/版本号/配置项。
