# MySQL 数据库 学习路线

> **生成日期**：2026-05-08  
> **说明**：路线基于当时可查的公开资料与主流实践整理。MySQL 版本迭代与支持策略以 [MySQL 官方文档门户](https://dev.mysql.com/doc/) 与对应版本的 **Release Notes / Lifetime** 为准；学习过程中应以官方文档为权威来源。

## 领域概述

MySQL 是最常用的开源关系型数据库之一，广泛用于 Web 后台、业务系统与数据分析入库环节。系统学习 MySQL 通常包括：在本地或容器中建好环境、掌握 SQL 与表设计、理解事务与 InnoDB 行为、具备备份恢复与基础排障能力，并能在需要时使用执行计划与监控做初步优化。

**当前生态要点（检索摘要）**：官方文档以 [MySQL Documentation](https://dev.mysql.com/doc/) 为入口；长期支持可关注官方标注的 **LTS** 路线（文档中常见 **MySQL 8.4** 参考手册等）。若你仍在使用较旧小版本，升级路径与生命周期请以对应版本的 Release Notes 为准。

## 学习原则

- 先读官方手册中与当前版本匹配的章节，再分散阅读博文与视频。
- 每一阶段配合本仓库该阶段 `demo/` 中的 SQL 与脚本动手，再进入下一阶段。
- 概念（隔离级别、索引、执行计划）尽量用「小例子 + 官方术语」对照理解，避免只靠口诀。

## 各阶段详情

### 阶段 1：安装与环境 · 库表与基础 SQL

- **目标**：完成 MySQL 服务端与本机客户端工具链；理解「实例 / 库 / 表 / 行」；掌握 `SELECT`/`INSERT`/`UPDATE`/`DELETE` 与条件、排序、分页。
- **核心主题**：安装与配置概要；`mysql` 客户端或图形工具；`CREATE DATABASE/TABLE`；数据类型初识；`WHERE`/`ORDER BY`/`LIMIT`。
- **实践要点**：从零创建业务无关的练习库；导入小样本数据；写多条查询对比结果。
- **推荐阅读**：在撰写本阶段 `THEORY.md` 时检索并写入官方「安装 / 教程 / SQL 语法」入口的完整 URL（见该文件文末）。

### 阶段 2：数据类型 · 约束 · 索引基础

- **目标**：避免「所有字段 VARCHAR」；掌握常见数值、字符串、日期时间与 JSON（若版本支持）的取舍；建立约束与索引的基本直觉。
- **核心主题**：类型选择与精度；`NULL` 语义；`PRIMARY KEY`/`UNIQUE`/`FOREIGN KEY`/`CHECK`；单列索引、最左前缀（为阶段 6 铺垫）。
- **实践要点**：设计 2–3 张有外键的表；用 `EXPLAIN` 提前看一眼「有没有用上索引」（不深究）。
- **推荐阅读**：官方 Reference Manual 中 **Data Types**、**CREATE TABLE**、**CREATE INDEX** 相关章节；撰写时用检索核对 URL。

### 阶段 3：查询进阶 · JOIN · 聚合与子查询

- **目标**：能写出多表业务查询；掌握分组统计与条件过滤；了解视图与存储程序何时适用。
- **核心主题**：`INNER/LEFT/RIGHT` JOIN；`GROUP BY`/`HAVING`；子查询与关联子查询；视图；存储过程/函数（可选，保持薄入口）。
- **实践要点**：基于阶段 2 的表完成报表类查询；至少一道「关联 + 聚合」综合题。
- **推荐阅读**：官方 **SELECT**、**Join**、**Subqueries**、**Views** 文档入口。

### 阶段 4：事务 · 锁 · 隔离级别

- **目标**：理解事务边界与提交/回滚；能用自己的话解释脏读、不可重复读、幻读与隔离级别；知道锁与死锁的表层原因。
- **核心主题**：`START TRANSACTION`/`COMMIT`/`ROLLBACK`；`READ COMMITTED`/`REPEATABLE READ` 等；元数据锁与行锁的直观介绍（深度控制在入门）。
- **实践要点**：两个会话并发执行同一组 SQL，观察隔离级别设置下的现象差异（若环境允许）。
- **推荐阅读**：官方 **InnoDB** 事务与锁、**SET TRANSACTION** 相关章节。

### 阶段 5：InnoDB 要点 · 备份恢复 · 权限与运维入门

- **目标**：默认存储引擎行为有概念图；能完成逻辑备份与恢复演练；会建用户、授权与最小权限原则；会查错误日志与基本状态。
- **核心主题**：InnoDB 缓冲池与表空间（概念层）；`mysqldump` 或官方推荐工具链；`CREATE USER`/`GRANT`；慢查询日志入口。
- **实践要点**：备份再恢复到新库名；为应用账号单独授权并验证。
- **推荐阅读**：官方 **Backup and Recovery**、**Security**、**Server Administration** 入口。

### 阶段 6：性能优化入门 · EXPLAIN · 工程实践

- **目标**：会用 `EXPLAIN`/`EXPLAIN ANALYZE`（视版本）判断全表扫描与索引使用；了解字符集/collation 常见问题；知道连接池与批量写入的基本共识。
- **核心主题**：执行计划列含义（入门）；覆盖索引直觉；慢查询分析流程；与 ORM/应用层协作的注意点（简要）。
- **实践要点**：人为制造无索引查询与加索引对比；记录优化前后计划差异。
- **推荐阅读**：官方 **Optimization**、**EXPLAIN** 章节；撰写时核对当前版本手册路径。

## 从基础到实践到进阶

本路线前三个阶段侧重 **SQL 与模型**，中间阶段建立 **事务与引擎** 心智模型，后两阶段进入 **可运维、可优化** 的工程视角。若你主攻数据分析而非应用开发，可在阶段 3 之后加大窗口函数与报表 SQL 比重；若主攻后端开发，阶段 4–6 应与日常接口设计与部署结合反复练。
