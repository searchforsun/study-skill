# Python 大模型应用开发 — 学习路线

> **生成日期**：2026-05-08  
> **说明**：路线基于当时可查的公开资料与主流实践整理；模型名称、SDK 接口与第三方文档 URL 会随版本迭代变化，学习过程中**请以各厂商官方文档与开源项目最新说明为准**。

## 领域概述

**Python 大模型应用开发**指在 Python 生态中，围绕云端或本地的大语言模型（LLM）构建可落地的应用：从单次 API 调用、提示与结构化输出，到检索增强（RAG）、工具调用与 Agent 编排，再到异步流式、Web 服务封装，以及观测、评估与安全运维。典型场景包括智能客服、文档问答、代码助手、内部知识库、自动化工作流等。

本路线按 **基础 → 实践（RAG / Agent / 服务）→ 优化（观测、安全、部署意识）** 递进；编排层以 **LangChain 生态（含 LangGraph）** 与 **官方模型 SDK（如 OpenAI Python）** 为主线，便于对照文档动手；若你更偏向纯 SDK 或 LlamaIndex 等栈，可在审阅阶段提出替换或并行支线。

## 学习原则

- 优先阅读 **官方文档与一手资料**（模型平台、SDK、LangChain/LangGraph 文档），再参考博文与视频。
- 每一阶段先完成 **`demo/`** 中的最小可运行示例，再进入下一阶段。
- **模型名与价格策略以平台实时页面为准**；示例代码中宜使用环境变量与可切换的 `model` 配置，避免写死已下线模型。

## 各阶段详情

### 阶段 1：环境与 LLM 调用入门

- **目标**：在隔离环境中跑通「一次完整的对话请求」，理解 `messages`、角色（system / user / assistant 等）、同步与异步客户端差异；建立 token 与费用的粗粒度认识。
- **核心主题**：Python 3.10+ 与虚拟环境；API Key 与环境变量；OpenAI 兼容接口的常见形态（以官方 Python SDK 为主）；错误类型与重试意识。
- **实践要点**：最小脚本调用；打印用量字段（若 API 返回）；切换模型名为配置项。
- **推荐阅读**：将在阶段 **`THEORY.md`** 撰写时用 **WebSearch** 检索并写入 **完整 URL**（如 OpenAI Python 参考、Chat Completions 指南等），并附检索关键词。

### 阶段 2：提示工程与结构化输出

- **目标**：把「写得像样」的提示固化成工程里可维护的模板；让模型按约定格式输出，便于下游解析。
- **核心主题**：指令、示例（few-shot）、输出约束；JSON mode / schema 类约束（以当前 SDK 能力为准）；简单对话记忆（上下文窗口内）。
- **实践要点**：模板 + 变量注入；解析失败时的降级策略。
- **推荐阅读**：官方「文本生成 / 结构化输出」类文档 + LangChain `ChatPromptTemplate` 等（撰写阶段即时检索 URL）。

### 阶段 3：RAG 与向量检索

- **目标**：基于私有文档回答用户问题，理解「检索 → 拼装上下文 → 生成」流水线及各环节失效模式。
- **核心主题**：文档加载与切分、嵌入（embedding）、向量数据库或内存检索；Hybrid 检索仅作扩展提及（按课时可选）。
- **实践要点**：小规模 Markdown/PDF 试用；chunk 大小与 overlap 实验；引用片段防止胡编（基础层面）。
- **推荐阅读**：LangChain RAG / retrieval 文档、所选向量库官方文档（撰写时检索）。

### 阶段 4：工具调用与 Agent 编排

- **目标**：让模型在需要时调用外部函数（查询、计算、API），并能把多步推理串成可控流程。
- **核心主题**：Tool / function calling；Agent 循环与终止条件；LangGraph 的状态、节点、边（入门）；与「单纯链式调用」的对比。
- **实践要点**：2–3 个模拟工具；调试模型选错工具或参数时的处理。
- **推荐阅读**：LangChain Agents、LangGraph 官方文档（撰写时检索 URL）。

### 阶段 5：异步流式与应用服务化

- **目标**：面向真实交互：流式返回降低首字延迟；用轻量 Web 层暴露为 HTTP 服务。
- **核心主题**：流式 chunk 处理；`async` 与并发限制；FastAPI 路由、依赖注入配置密钥；日志与请求 ID。
- **实践要点**：终端或简单前端可消费的 SSE/流式示例；并发上限与背压的粗浅说明。
- **推荐阅读**：FastAPI 文档、所用 SDK 的 streaming 章节（撰写时检索）。

### 阶段 6：观测评估与安全运维

- **目标**：能看见线上行为（tracing）、能回答「效果好不好」的一部分（最小评估），并具备基础安全意识。
- **核心主题**：LangSmith 或同类 tracing；简单 golden set / LLM-as-judge 的介绍级实践；提示注入、密钥泄露、PII 的基本防范；容器/环境变量与配置分离。
- **实践要点**：为一条链路加 trace；列一份安全检查清单并在 demo 中体现 1–2 条。
- **推荐阅读**：LangSmith、OpenAI 安全最佳实践或平台安全文档（撰写时检索）。

## 从基础到实践到进阶

- **基础（阶段 1–2）**：建立调用范式与提示、结构化输出习惯，避免一上来就堆框架。
- **实践（阶段 3–5）**：RAG 与 Agent 覆盖当前业界最常见的两类应用形态；服务化打通「可演示」闭环。
- **进阶（阶段 6）**：把应用从「能跑」推到「可观测、可迭代、可防守」的工程意识。
