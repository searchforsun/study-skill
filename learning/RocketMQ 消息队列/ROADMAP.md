# RocketMQ 消息队列 学习路线

> **生成日期**：2026-05-08  
> **说明**：路线基于当时可查的公开资料与主流实践整理。RocketMQ 5.x 演进较快（发布说明可参考官网 Release Notes），学习过程中请以 [Apache RocketMQ 官方网站](https://rocketmq.apache.org/) 与当前文档导航中的 **Quick Start / 部署 / Client** 章节为准。

## 领域概述

Apache RocketMQ 是分布式**消息中间件**，适用于异步解耦、削峰填谷、事件驱动与流式数据入口等场景。其核心抽象包括 **Topic、队列（Queue/MessageQueue）、生产者与消费者**，运行时依赖 **NameServer**（路由发现）与 **Broker**（存储与投递）。应用开发路线通常覆盖本地与集群环境的搭建、Java（及按需的其他语言）客户端 API、顺序与延时等特性、事务与高可靠模式，再到运维监控与生产实践。

## 学习原则

- 优先阅读官方文档与一手资料，再结合社区文章（注意客户端与 Broker 版本匹配）。
- 每一阶段在对应文件夹的 `demo/` 中完成可操作示例后，再进入下一阶段。
- **默认以 Java 客户端与官方推荐的本地/容器部署为主线**；若你使用 Go、Python 等客户端，可在对应阶段对照官方文档调整命令与 API。

## 路线图（自上而下）

```
架构 / NameServer / Broker / 本地或容器跑通集群
                ↓
Topic · 生产者 / 消费者 · 集群与广播 · 发送与消费语义入门
                ↓
顺序消息 · 延时 / 定时 · 过滤（Tag/SQL）· Pull/Push 心智模型
                ↓
事务消息 · 幂等与重复消费 · 死信与重试策略（概念 + 实验）

                ↓
综合实践（Spring Boot 集成或小场景闭环）· 性能与参数入门
```

## 各阶段详情

### 阶段 1：架构入门与本地运行

- **目标**：建立 RocketMQ 拓扑心智模型，能在本机完成「路由可达 + 消息落盘 + 消费确认」的最小闭环。
- **核心主题**：NameServer、Broker、Topic、Queue/MessageQueue；官网 Quick Start 推荐的本地部署路径（二进制或容器，二选一为主）。
- **实践要点**：创建 Topic；使用官方示例或命令行工具验证生产与消费；查看 Broker / NameServer 日志定位常见问题。
- **推荐阅读**：阶段 `**THEORY.md`** 中将收录撰写时检索得到的官方 Quick Start、架构概念章节链接与检索关键词。

### 阶段 2：生产者与消费者开发基础

- **目标**：熟练使用主流客户端 API，理解消费者组、负载均衡与至少一次投递语义下的业务含义。
- **核心主题**：`DefaultMQProducer`、`DefaultMQPushConsumer`（或当前文档推荐的等价 API）；消息结构与属性；消费线程与并发；集群消费 vs 广播消费。
- **实践要点**：多种发送调用方式对比；同一消费者组扩容消费者观察分配变化（概念可由日志与现象印证）。
- **推荐阅读**：官方 Producer / Consumer 文档 URL（写入阶段 `THEORY.md`）。

### 阶段 3：顺序、延时与过滤

- **目标**：能根据业务选择顺序粒度与过滤方式，理解能力与代价。
- **核心主题**：全局顺序 vs 队列内顺序；延时 / 定时消息（功能随版本演进，以文档为准）；Tag 过滤与 SQL92 属性过滤。
- **实践要点**：顺序消息反例（跨队列无序）；过滤表达式实验。
- **推荐阅读**：对应特性章节与 Release Notes 中的行为变更说明。

### 阶段 4：事务、幂等与可靠性

- **目标**：理解 RocketMQ 事务消息协作流程，能在业务侧设计幂等与补偿。
- **核心主题**：事务消息状态机；本地事务与回查；重复消息与业务幂等键；消费失败重试与 **DLQ（死信）** 的定位。
- **实践要点**：最小事务消息示例；模拟异常观察半消息与回查路径（日志辅助）。
- **推荐阅读**：事务消息专题文档与最佳实践文章（链接写入 `THEORY.md`，区分官方与社区）。

### 阶段 5：集群运维与可观测性

- **目标**：了解生产常见部署拓扑与基本运维动作，能使用 Dashboard 与指标做初步诊断。
- **核心主题**：Broker 集群、NameServer 无状态扩展概念；权限与 ACL（若启用）；Dashboard 或控制台工具链；堆积、延迟与重启消费的初步判断。
- **实践要点**：本地模拟多 Broker 或查阅文档完成拓扑图理解；监控指标入口演练。
- **推荐阅读**：Deployment、Operations、Metrics 相关官方章节。

### 阶段 6：综合实践与进阶入门

- **目标**：贯穿「业务 → Topic 设计 → 生产消费 → 异常处理」，形成可演示的小项目或模块。
- **核心主题**：Topic / Tag 划分原则回顾；与 Spring Boot 集成（可选）；文件、批量、压缩等参数入门；何时需要升级 Broker / 客户端。
- **实践要点**：自选场景（通知、日志投递、任务队列等）实现 README 可复现；列出已知限制与后续优化方向。
- **推荐阅读**：官方示例仓库、社区案例（链接写入该阶段 `THEORY.md`）。

## 从基础到实践到进阶

本路线按 **架构与环境 → API 与消费模型 → 特性（顺序/延时/过滤）→ 高可靠（事务/幂等）→ 运维与可观测 → 综合项目** 递进。前四阶段侧重开发与语义；第五阶段连接线上运维现实；第六阶段用综合练习巩固并接触性能与框架集成。深入存储引擎、大规模集群调优可在工作后按需专题加深。
